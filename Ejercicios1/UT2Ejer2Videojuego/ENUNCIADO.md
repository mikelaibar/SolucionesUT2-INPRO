# Ejercicio 1.2

2. Perfil de un videojuego
En este ejercicio tendrás que decidir qué tipo de dato es el más apropiado para representar diferentes características de un videojuego.
Crea un programa que almacene:
- Nombre del videojuego.
- Número de jugadores.
- Precio.
- Clasificación por edad mediante una única letra.
- Si dispone de modo multijugador.
- Valoración media de los usuarios con decimales.
Elige tú mismo los valores que quieras almacenar.
Finalmente, muestra todos los datos utilizando Console.WriteLine().
Importante: antes de programar, piensa qué tipo de dato es el más apropiado para cada variable.
Nombre del proyecto: UT2Ejer2Videojuego
