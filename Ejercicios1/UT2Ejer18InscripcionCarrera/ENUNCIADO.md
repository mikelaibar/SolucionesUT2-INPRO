# Ejercicio 1.18

18. Inscripción a una carrera
En este ejercicio tendrás que transformar unas reglas escritas en expresiones de C# sin recibir las expresiones ya preparadas.
Una carrera deportiva dispone de la siguiente información sobre un participante:
int edad = 17;
bool tieneAutorizacion = true;
bool inscripcionPagada = true;
bool documentacionEntregada = true;
double marcaAnterior = 52.30;
Crea las variables booleanas necesarias para representar las siguientes reglas:
- Es mayor de edad.
- Puede participar por edad: es mayor de edad o tiene autorización.
- Tiene todos los trámites administrativos completados: inscripción pagada y documentación entregada.
- Puede participar: cumple el requisito de edad y tiene todos los trámites completados.
- Tiene una marca inferior a 55 minutos.
- Puede entrar en el grupo avanzado si puede participar y además tiene una marca inferior a 55 minutos.
Muestra por consola los resultados obtenidos.
Importante: no escribas directamente true o false. Cada resultado debe obtenerse mediante una expresión.
