# Ejercicio 1.8

8. Rescata el programa
Un programador ha intentado crear la ficha de un usuario, pero ha cometido varios errores relacionados con los tipos de datos.
Copia el siguiente código en Visual Studio Code:
int edad = "24";
double altura = "1.78";
char inicial = "M";
string nombre = 'Mario';
bool activo = "true";
int? puntos = null;
double temperatura = 36,7;
string telefono = 654123987;
Console.WriteLine(nombre);
Console.WriteLine(edad);
Console.WriteLine(altura);
Console.WriteLine(inicial);
Console.WriteLine(activo);
Console.WriteLine(puntos);
Console.WriteLine(temperatura);
Console.WriteLine(telefono);
El programa contiene diferentes errores. Tu trabajo consiste en:
- Ejecutar el programa y observar los errores que muestra Visual Studio Code.
- Localizar las declaraciones incorrectas.
- Corregir los tipos o los valores según corresponda.
- Conseguir que el programa pueda ejecutarse correctamente.
Importante: no elimines ninguna variable. Debes conseguir que todas representen correctamente la información indicada por su nombre.
Nombre del proyecto: UT2Ejer8RescataPrograma
