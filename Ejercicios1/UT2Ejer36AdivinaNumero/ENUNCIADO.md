# Ejercicio 1.36

36. Adivina el número
Ahora combinarás un while, entrada por teclado, condicionales y break.
El programa tendrá almacenado:
int numeroSecreto = 37;
El jugador deberá introducir números utilizando Console.ReadLine() hasta encontrar el número secreto.
Después de cada intento:
- Si el número es menor que el secreto, muestra El número secreto es mayor.
- Si es mayor, muestra El número secreto es menor.
- Si coincide, muestra ¡Has acertado! y utiliza break.
El jugador dispone como máximo de 7 intentos.
Al finalizar muestra también:
Intentos utilizados: ...
Si consume los siete intentos sin encontrar el número, muestra:
Has perdido. El número secreto era 37.
Nombre del proyecto: UT2Ejer36AdivinaNumero
