# Ejercicio 1.20

20. Campeonato de videojuegos
En este último ejercicio tendrás que diseñar prácticamente todo el programa a partir de un caso real, combinando los diferentes operadores estudiados.
Un campeonato de videojuegos necesita analizar los datos de un jugador. Se conoce la siguiente información:
- Nombre del jugador.
- Partidas jugadas.
- Partidas ganadas.
- Puntos obtenidos.
- Número de penalizaciones.
- Si ha pagado la inscripción.
- Si su cuenta está activa.
- Si ha sido sancionado.
Elige tú mismo los valores iniciales y crea las variables necesarias.
Después, utilizando operadores, calcula y almacena:
- El número de partidas que no ha ganado.
- La media de puntos por partida. El resultado debe conservar decimales.
- Si ha ganado al menos 5 partidas.
- Si su media de puntos es igual o superior a 100.
- Si tiene menos de 3 penalizaciones.
- Si puede participar: inscripción pagada, cuenta activa y no sancionado.
- Si cumple los requisitos deportivos: al menos 5 victorias, media de 100 puntos o superior y menos de 3 penalizaciones.
- Si puede clasificarse: puede participar y cumple los requisitos deportivos.
Finalmente, muestra un informe completo:
--- INFORME DEL JUGADOR ---
Jugador: ...
Partidas: ...
Victorias: ...
Partidas no ganadas: ...
Media de puntos: ...
Puede participar: ...
Cumple requisitos deportivos: ...
Puede clasificarse: ...
Importante: todavía no debes utilizar if. Todos los resultados deben obtenerse mediante operaciones y almacenarse en variables.
Reto final: cambia los datos iniciales del jugador e intenta conseguir primero que puedeClasificarse tenga valor true y después que tenga valor false.
