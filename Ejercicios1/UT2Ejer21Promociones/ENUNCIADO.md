# Ejercicio 1.21

21. Promociones de una tienda
En este primer ejercicio utilizarás varios condicionales if independientes para comprobar diferentes promociones de una tienda.
Parte de los siguientes datos:
double compra = 85.50;
int productos = 6;
bool esSocio = true;
El programa deberá realizar las siguientes comprobaciones:
- Si la compra supera los 50 €, muestra Envío gratuito.
- Si se han comprado 5 productos o más, muestra Regalo promocional incluido.
- Si el cliente es socio, muestra Acumulas puntos con esta compra.
- Si la compra supera los 100 €, muestra Cupón de 10 € para tu próxima compra.
Utiliza un if diferente para cada comprobación. Un mismo cliente puede cumplir varias condiciones y recibir varios mensajes.
Modifica después los valores iniciales para comprobar diferentes resultados.
Nombre del proyecto: UT2Ejer21Promociones
