# Ejercicio 1.10

10. Diseña tu propio sistema
En el último ejercicio pondrás en práctica todo lo aprendido sobre variables y tipos de datos diseñando un pequeño sistema desde cero.
Elige uno de los siguientes sistemas:
- Una ficha de una película de una plataforma de streaming.
- El perfil de un personaje de un videojuego.
- La ficha de un ordenador de una tienda.
- La información de una reserva de hotel.
- La ficha de un jugador de un equipo deportivo.
Tu programa deberá contener como mínimo 10 variables y deberá utilizar obligatoriamente:
- Al menos una variable int.
- Al menos una variable double o float.
- Al menos una variable bool.
- Al menos una variable char.
- Al menos dos variables string.
- Al menos una variable de un tipo nullable.
Los nombres de las variables deben ser descriptivos y seguir las convenciones utilizadas durante el tema.
Asigna valores coherentes a las variables y utiliza Console.WriteLine() para mostrar toda la información de manera clara y organizada.
Reto: intenta que una persona que ejecute tu programa pueda entender toda la información sin necesidad de consultar el código.
Nombre del proyecto: UT2Ejer10MiSistema
