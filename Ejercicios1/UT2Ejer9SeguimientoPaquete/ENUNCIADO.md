# Ejercicio 1.9

9. Seguimiento de un paquete
Ahora tendrás menos indicaciones. Tendrás que diseñar tú las variables necesarias para representar correctamente la información.
Una empresa de transporte necesita mostrar la información de seguimiento de un paquete.
Sabemos que:
- El paquete tiene un código de seguimiento que puede contener números y letras.
- Se conoce el nombre del destinatario.
- Se conoce el peso del paquete con decimales.
- Se conoce el número de intentos de entrega realizados.
- Queremos saber si el paquete ha sido entregado.
- La zona de reparto se identifica mediante una única letra.
- La valoración del servicio todavía no existe porque el paquete no ha sido entregado.
Crea todas las variables que consideres necesarias, elige un nombre descriptivo y selecciona correctamente su tipo.
Después asigna valores y muestra una ficha de seguimiento organizada por consola.
En este ejercicio no se indican los nombres ni los tipos de las variables: debes decidirlos tú.
Nombre del proyecto: UT2Ejer9SeguimientoPaquete
