# Ejercicio 1.3

3. Ficha de un producto
Ahora crearás un pequeño programa para representar la información de un producto de una tienda.
Declara y asigna valores a variables que permitan almacenar:
- Nombre del producto.
- Código del producto, por ejemplo "00125A".
- Precio.
- Número de unidades disponibles.
- Si está disponible para la venta.
- Letra de la sección en la que se encuentra.
Muestra después una ficha similar a la siguiente:
--- PRODUCTO ---
Nombre: Teclado mecánico
Código: 00125A
Precio: 49.95
Unidades: 12
Disponible: True
Sección: I
Piensa: aunque un dato contenga números, no siempre significa que deba almacenarse utilizando int.
Nombre del proyecto: UT2Ejer3Producto
