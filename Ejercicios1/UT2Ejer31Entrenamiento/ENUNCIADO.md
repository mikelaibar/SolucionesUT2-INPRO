# Ejercicio 1.31

31. Entrenamiento por vueltas
En este primer ejercicio utilizarás un bucle for para procesar una cantidad conocida de repeticiones.
Un deportista realiza 10 vueltas a un circuito. Crea un programa que muestre el número de cada vuelta:
Vuelta 1
Vuelta 2
Vuelta 3
...
Vuelta 10
Además:
- Cada 3 vueltas debe mostrar el mensaje Punto de hidratación.
- En la vuelta 5 debe mostrar Mitad del entrenamiento aproximadamente.
- Después de finalizar el bucle debe mostrar Entrenamiento completado.
Utiliza un único bucle for y los condicionales que necesites.
Nombre del proyecto: UT2Ejer31Entrenamiento
