# Ejercicio 1.37

37. Menú de una aplicación
Los menús son uno de los usos habituales de do-while, ya que deben mostrarse al menos una vez.
Crea el siguiente menú:
--- MENÚ ---
1. Mostrar saludo
2. Mostrar curso académico
3. Mostrar nombre del módulo
4. Salir
Selecciona una opción:
Lee la opción utilizando Console.ReadLine() y utiliza un switch para ejecutar la acción correspondiente.
- 1: muestra un saludo.
- 2: muestra Curso 2026/2027.
- 3: muestra Iniciación a la Programación.
- 4: muestra Cerrando programa....
- Cualquier otro valor: Opción incorrecta.
El menú debe volver a aparecer después de ejecutar cada opción y finalizar únicamente cuando el usuario seleccione la opción 4.
En este ejercicio estás combinando dos estructuras diferentes: do-while controla la repetición del menú y switch decide qué acción ejecutar.
