# Ejercicio 1.34

34. Objetivo de ventas
No siempre sabemos de antemano cuántas repeticiones serán necesarias. En este ejercicio utilizarás un bucle while.
Una empresa comienza el mes con:
double ventas = 1000;
double objetivo = 5000;
double ventasDiarias = 650;
int dia = 0;
Cada día se consiguen 650 € adicionales en ventas.
Utiliza un while para simular el paso de los días hasta alcanzar o superar el objetivo.
En cada iteración muestra:
Día 1 - Ventas acumuladas: ...
Día 2 - Ventas acumuladas: ...
...
Al finalizar muestra:
Objetivo alcanzado
Días necesarios: ...
Piensa por qué un while representa mejor este problema que un for.
Nombre del proyecto: UT2Ejer34ObjetivoVentas
