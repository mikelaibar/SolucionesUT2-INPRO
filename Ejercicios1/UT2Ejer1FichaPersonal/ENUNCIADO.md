# Ejercicio 1.1

1. Mi primera ficha
En este ejercicio crearás tu primer programa utilizando diferentes tipos de datos de C#.
Crea las variables necesarias para almacenar la siguiente información sobre una persona:
- Nombre.
- Edad.
- Altura en metros.
- Inicial del primer apellido.
- Si tiene carnet de conducir.
Asigna un valor a cada variable y utiliza Console.WriteLine() para mostrar toda la información por consola.
Por ejemplo, la salida podría ser:
Nombre: Ane
Edad: 19
Altura: 1.72
Inicial del apellido: G
Tiene carnet: False
Nombre del proyecto: UT2Ejer1FichaPersonal
