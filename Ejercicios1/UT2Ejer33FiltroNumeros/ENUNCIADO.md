# Ejercicio 1.33

33. Filtro de números
En este ejercicio utilizarás continue para ignorar determinadas iteraciones de un bucle.
Recorre mediante un for todos los números comprendidos entre 1 y 50.
El programa deberá aplicar estas reglas:
- Si el número es múltiplo de 3, utiliza continue para ignorarlo completamente.
- De los números restantes, muestra únicamente los pares.
- Cuenta cuántos números se han mostrado.
- Suma todos los números que se han mostrado.
Al finalizar muestra:
Cantidad de números mostrados: ...
Suma total: ...
Importante: utiliza obligatoriamente continue. No resuelvas todo mediante una única condición compleja.
Nombre del proyecto: UT2Ejer33FiltroNumeros
