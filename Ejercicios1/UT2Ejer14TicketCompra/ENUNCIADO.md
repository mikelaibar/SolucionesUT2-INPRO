# Ejercicio 1.14

14. Ticket de compra
En este ejercicio combinarás diferentes operaciones aritméticas para calcular el precio de una compra.
Una persona compra los siguientes productos:
double precioCamiseta = 19.95;
int cantidadCamisetas = 2;
double precioPantalon = 35.50;
int cantidadPantalones = 1;
Crea las variables y operaciones necesarias para calcular:
- El coste total de las camisetas.
- El coste total de los pantalones.
- El precio total de la compra.
Muestra un ticket similar al siguiente:
--- TICKET ---
Camisetas: ...
Pantalones: ...
TOTAL: ...
No escribas directamente el resultado de ninguna operación en el Console.WriteLine(). Guarda primero los resultados importantes en variables.
Nombre del proyecto: UT2Ejer14TicketCompra
