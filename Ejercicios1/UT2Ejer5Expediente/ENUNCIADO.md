# Ejercicio 1.5

5. Expediente de un alumno
No toda la información está siempre disponible. En este ejercicio comenzarás a trabajar con valores null.
Crea un programa que represente el expediente de un alumno mediante las siguientes variables:
- Nombre del alumno.
- Edad.
- Grupo.
- Nota del primer examen.
- Nota del segundo examen, que todavía no ha sido corregido.
- Si ha entregado el proyecto.
La nota del segundo examen deberá comenzar con el valor null.
Recuerda: si una variable numérica puede contener null, tendrás que utilizar un tipo nullable como double?.
Muestra posteriormente los valores de todas las variables.
Nombre del proyecto: UT2Ejer5Expediente
