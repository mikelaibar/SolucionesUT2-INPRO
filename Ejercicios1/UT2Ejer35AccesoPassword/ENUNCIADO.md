# Ejercicio 1.35

35. Acceso con contraseña
En este ejercicio utilizarás un while para repetir una acción hasta que se produzca una determinada situación.
La contraseña correcta del sistema es:
string passwordCorrecta = "CSharp123";
Utiliza Console.ReadLine() para pedir al usuario una contraseña.
El usuario dispone de un máximo de 5 intentos.
- Si la contraseña es incorrecta, muestra Contraseña incorrecta.
- Después de cada error muestra cuántos intentos quedan.
- Si introduce la contraseña correcta, muestra Acceso concedido y termina el bucle utilizando break.
- Si consume los 5 intentos sin acertar, muestra Cuenta bloqueada.
Controla cuidadosamente cuándo debes incrementar el contador de intentos y cuándo debe terminar el bucle.
Nombre del proyecto: UT2Ejer35AccesoPassword
