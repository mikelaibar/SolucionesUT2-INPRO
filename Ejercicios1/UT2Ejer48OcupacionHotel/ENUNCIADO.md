# Ejercicio 1.48

48. Ocupación de un hotel
En esta actividad utilizarás bucles anidados para procesar las habitaciones de varias plantas de un hotel.
Pregunta al usuario:
Número de plantas del hotel:
Habitaciones por planta:
A continuación deberás recorrer todas las habitaciones. Por ejemplo, si existen 3 plantas con 4 habitaciones cada una:
Planta 1 - Habitación 1
Planta 1 - Habitación 2
Planta 1 - Habitación 3
Planta 1 - Habitación 4
Planta 2 - Habitación 1
...
Para cada habitación, pregunta:
¿Está ocupada? (S/N):
Si se introduce un valor distinto de S o N, vuelve a solicitar la respuesta para esa misma habitación.
Durante el recorrido lleva un recuento de:
- Habitaciones totales.
- Habitaciones ocupadas.
- Habitaciones libres.
Al finalizar muestra:
--- OCUPACIÓN DEL HOTEL ---
Habitaciones totales: ...
Ocupadas: ...
Libres: ...
Porcentaje de ocupación: ... %
Necesitarás un bucle para recorrer las plantas y otro dentro de él para recorrer las habitaciones de cada planta.
Nombre del proyecto: UT2Ejer48OcupacionHotel
