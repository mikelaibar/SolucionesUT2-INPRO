# Ejercicio 1.27

27. Calculadora por operaciones
Ahora combinarás un switch con los operadores aritméticos trabajados anteriormente.
Dispones de:
double numero1 = 20;
double numero2 = 5;
char operacion = '*';
La variable operacion podrá contener:
- '+' para sumar.
- '-' para restar.
- '*' para multiplicar.
- '/' para dividir.
Utiliza un switch para realizar la operación correspondiente y mostrar el resultado.
Si el carácter almacenado no corresponde con ninguna operación, muestra Operación no válida.
Ampliación: controla mediante un if qué sucede si se intenta dividir entre cero.
Nombre del proyecto: UT2Ejer27CalculadoraSwitch
