# Ejercicio 1.7

7. Registro de una cita médica
Crea una ficha de un paciente que acaba de llegar al centro y todavía no tiene consulta asignada. Selecciona los tipos apropiados para los siguientes datos:
- Nombre del paciente.
- Número de tarjeta sanitaria.
- Edad.
- Temperatura corporal.
- Si tiene fiebre.
- Número de consulta asignada, que todavía puede no conocerse.
- Inicial del profesional que le atenderá.
Supón que el paciente acaba de llegar y todavía no tiene una consulta asignada.
Declara correctamente todas las variables, asigna valores y muestra una ficha completa por consola.
Antes de programar: identifica qué variable debe poder almacenar null y decide cuál será su tipo.
El número de tarjeta sanitaria es un identificador: guárdalo como texto para conservar cualquier cero inicial. Usa grados Celsius para la temperatura y un número de consulta nullable, inicializado a null. Asigna un valor coherente al dato booleano de fiebre; no tienes que calcularlo mediante una regla nueva.
Nombre del proyecto: UT2Ejer7CitaMedica
