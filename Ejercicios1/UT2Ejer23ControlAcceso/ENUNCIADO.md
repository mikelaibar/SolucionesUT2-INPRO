# Ejercicio 1.23

23. Control de acceso
Ahora combinarás operadores lógicos con una estructura if-else.
Una aplicación dispone de la siguiente información:
string usuario = "mikel";
string password = "abc123";
bool cuentaActiva = true;
Para acceder deben cumplirse simultáneamente estas tres condiciones:
- El usuario debe ser "mikel".
- La contraseña debe ser "abc123".
- La cuenta debe estar activa.
Si se cumplen todos los requisitos muestra:
Acceso concedido
En cualquier otro caso:
Acceso denegado
Prueba posteriormente a modificar individualmente el usuario, la contraseña y el estado de la cuenta.
Nombre del proyecto: UT2Ejer23ControlAcceso
