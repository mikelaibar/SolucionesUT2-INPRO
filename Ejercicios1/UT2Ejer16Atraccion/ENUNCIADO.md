# Ejercicio 1.16

16. Acceso a una atracción
En este ejercicio utilizarás operadores de comparación y operadores lógicos para representar las reglas de acceso a una atracción.
Disponemos de los siguientes datos:
int edad = 14;
double altura = 1.55;
bool tieneEntrada = true;
bool vaAcompanado = false;
Para cada una de las siguientes reglas crea una variable bool que almacene si se cumple o no:
- La persona tiene 12 años o más.
- La persona mide al menos 1.50 metros.
- Tiene edad suficiente Y altura suficiente.
- Tiene entrada Y cumple los requisitos de edad y altura.
- Puede acceder si cumple todos los requisitos anteriores O va acompañada.
Muestra el resultado de cada comprobación por consola.
Todavía no necesitas utilizar if. Una expresión lógica puede almacenarse directamente en una variable bool.
Nombre del proyecto: UT2Ejer16Atraccion
