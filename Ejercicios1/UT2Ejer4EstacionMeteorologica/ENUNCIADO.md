# Ejercicio 1.4

4. Estación meteorológica
En este ejercicio representarás mediante variables las mediciones realizadas por una pequeña estación meteorológica.
Tu programa debe almacenar:
- Nombre de la localidad.
- Temperatura actual con decimales.
- Humedad como un número entero.
- Si está lloviendo.
- Dirección principal del viento mediante una letra.
- Velocidad del viento con decimales.
Asigna valores a todas las variables y muestra un pequeño informe por consola.
--- ESTACIÓN METEOROLÓGICA ---
Localidad: Pamplona
Temperatura: 16.5
Humedad: 72
Está lloviendo: False
Dirección del viento: N
Velocidad del viento: 12.7
Nombre del proyecto: UT2Ejer4EstacionMeteorologica
