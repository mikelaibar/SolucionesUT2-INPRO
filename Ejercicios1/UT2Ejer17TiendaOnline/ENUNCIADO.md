# Ejercicio 1.17

17. Condiciones de una tienda online
Una tienda online necesita comprobar diferentes situaciones utilizando expresiones booleanas.
Declara las siguientes variables:
double totalCompra = 67.50;
bool esPremium = false;
bool tieneCupon = true;
int productos = 4;
Crea una variable bool diferente para cada una de estas situaciones:
- La compra supera los 50 €.
- El cliente es Premium.
- El cliente tiene un cupón y ha comprado al menos 3 productos.
- Obtiene envío gratuito si la compra supera los 50 € o es Premium.
- Puede utilizar una promoción especial si es Premium o si tiene cupón y su compra supera los 30 €.
- No puede acceder a la promoción exclusiva si no es Premium.
Muestra todas las comprobaciones por consola indicando claramente qué representa cada resultado.
Nombre del proyecto: UT2Ejer17TiendaOnline
