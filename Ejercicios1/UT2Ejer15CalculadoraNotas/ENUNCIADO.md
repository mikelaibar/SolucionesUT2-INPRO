# Ejercicio 1.15

15. Calculadora de notas
Ahora tendrás que combinar operaciones y utilizar correctamente la precedencia de operadores.
Un alumno tiene las siguientes notas:
double examen1 = 6.5;
double examen2 = 8.0;
double examen3 = 5.5;
Calcula la nota media de los tres exámenes y almacénala en una nueva variable.
A continuación, crea una variable de tipo bool llamada aprobado cuyo valor indique si la nota media es mayor o igual que 5.
Muestra:
Nota 1: 6.5
Nota 2: 8
Nota 3: 5.5
Nota media: ...
¿Está aprobado?: ...
Cuidado: utiliza paréntesis correctamente para calcular la media.
Nombre del proyecto: UT2Ejer15CalculadoraNotas
