# Ejercicio 1.6

6. Vehículo de segunda mano
En una aplicación real podemos conocer algunos datos de un objeto y desconocer otros. Utilizarás diferentes tipos de datos y varios valores nullable.
Crea un programa para almacenar la información de un vehículo de segunda mano:
- Marca.
- Modelo.
- Matrícula.
- Año de fabricación.
- Precio.
- Kilómetros recorridos.
- Si tiene la ITV en vigor.
- Número de propietarios anteriores, que puede ser desconocido.
- Consumo medio, que puede ser desconocido.
En este vehículo concreto se desconoce tanto el número de propietarios anteriores como su consumo medio. Inicializa ambos datos con null.
Después muestra toda la información disponible por consola.
Nombre del proyecto: UT2Ejer6Vehiculo
