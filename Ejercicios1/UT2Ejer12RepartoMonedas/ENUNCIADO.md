# Ejercicio 1.12

12. Reparto de monedas
En este ejercicio utilizarás la división entera y el operador % para resolver un pequeño problema de reparto.
Disponemos de:
int monedas = 23;
int jugadores = 4;
Calcula mediante operadores:
- Cuántas monedas recibe cada jugador si todos deben recibir la misma cantidad.
- Cuántas monedas sobran después del reparto.
Guarda ambos resultados en variables y muéstralos por consola.
Monedas disponibles: 23
Jugadores: 4
Monedas por jugador: 5
Monedas sobrantes: 3
Modifica después el valor de monedas y comprueba cómo cambia el resultado.
Nombre del proyecto: UT2Ejer12RepartoMonedas
