# Ejercicio 1.32

32. Plan de ahorro
Ahora utilizarás un for junto con un acumulador para representar cómo cambia una cantidad durante varias iteraciones.
Una persona comienza con:
double ahorros = 100;
double ahorroMensual = 50;
Simula mediante un for el ahorro durante 12 meses.
Cada mes deberás:
- Sumar ahorroMensual a los ahorros.
- Mostrar el número del mes.
- Mostrar el dinero acumulado hasta ese momento.
La salida tendrá una estructura similar a:
Mes 1 - Ahorros: 150 €
Mes 2 - Ahorros: 200 €
Mes 3 - Ahorros: 250 €
...
Al terminar muestra el dinero total acumulado.
Ampliación: cada 6 meses se recibe además una paga extra de 100 €. Modifica el programa para incorporarla.
Nombre del proyecto: UT2Ejer32PlanAhorro
