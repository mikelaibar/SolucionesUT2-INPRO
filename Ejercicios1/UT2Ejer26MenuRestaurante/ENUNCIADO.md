# Ejercicio 1.26

26. Menú de un restaurante
En este ejercicio utilizarás por primera vez switch para seleccionar una acción según el valor de una variable.
Un restaurante dispone del siguiente menú:
1 - Hamburguesa
2 - Pizza
3 - Ensalada
4 - Bocadillo
5 - Salir
Declara una variable:
int opcion = 2;
Utiliza switch para mostrar:
- 1 → Has elegido Hamburguesa - 9.50 €
- 2 → Has elegido Pizza - 11.00 €
- 3 → Has elegido Ensalada - 8.00 €
- 4 → Has elegido Bocadillo - 7.50 €
- 5 → Hasta pronto
- Cualquier otro número → Opción incorrecta
Prueba el programa modificando varias veces el valor de opcion.
Nombre del proyecto: UT2Ejer26MenuRestaurante
