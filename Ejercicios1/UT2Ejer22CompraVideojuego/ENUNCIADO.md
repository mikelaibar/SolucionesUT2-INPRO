# Ejercicio 1.22

22. Compra de un videojuego
En este ejercicio utilizarás if-else para hacer que el programa elija entre dos posibles caminos.
Dispones de:
double saldo = 45.00;
double precioVideojuego = 39.99;
El programa debe comprobar si el usuario dispone de suficiente dinero para comprar el videojuego.
- Si tiene suficiente saldo, resta el precio del videojuego y muestra Compra realizada correctamente.
- En caso contrario, muestra Saldo insuficiente.
Al finalizar, muestra también el saldo disponible.
Aquí ya no queremos dos if independientes. Las dos situaciones son excluyentes: o puede comprarlo o no puede.
Nombre del proyecto: UT2Ejer22CompraVideojuego
