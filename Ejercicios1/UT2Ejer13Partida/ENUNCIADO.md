# Ejercicio 1.13

13. Actualizando una partida
Los valores de las variables pueden cambiar durante la ejecución de un programa. En este ejercicio practicarás los operadores de asignación, incremento y decremento.
Parte de los siguientes datos:
int puntos = 100;
int vidas = 3;
int monedas = 10;
Durante la partida sucede lo siguiente:
- El jugador consigue 50 puntos.
- Recoge 5 monedas.
- Pierde una vida.
- Consigue el doble de los puntos que tenía.
- Gasta 3 monedas.
- Consigue una vida adicional.
Modifica las variables utilizando, cuando sea posible, operadores como +=, -=, *=, ++ y --.
Muestra al final el estado de la partida:
--- ESTADO DE LA PARTIDA ---
Puntos: ...
Vidas: ...
Monedas: ...
